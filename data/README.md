# Data Folder

The warranty claims data is confidential and is not included in this repository.

To run the notebook, place these files in this folder:

- `fy19-fy23_warranty_claims.csv` (training data, FY2019 to FY2023)
- `fy24_warranty_claims.csv` (validation data, FY2024)

Key columns used by the notebook: `Claimed Month`, `Accept/Reject status`, `RM`, `Model Name`, `Part category`.
